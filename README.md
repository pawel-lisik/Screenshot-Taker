# Screenshot-Taker (Windows)
A tool to take a screenshot, record a screen or take a screenshot of a selection of a screen.
Supports Windows dark mode, and automatically adjusts it's color to the system.

## Setup
Install using PyInstaller.

## Requirements

* mss 9.0.1
* numpy 1.26.0
* opencv-python 4.9.0
* PyAutoGUI 0.9.54
* PyQt5 5.15.10
